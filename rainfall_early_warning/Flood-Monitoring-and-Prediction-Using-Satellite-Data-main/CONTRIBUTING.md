# Contributing

Thank you for your interest in contributing to this project!

This repository was developed as a Bachelor of Technology major project focused on flood monitoring and prediction using Sentinel-1 SAR imagery, Remote Sensing, Google Earth Engine, and Deep Learning.

Contributions that improve documentation, code quality, reproducibility, or usability are welcome.

## How to Contribute

1. Fork the repository.
2. Create a new feature branch.

```bash
git checkout -b feature/your-feature-name
```

3. Commit your changes.

```bash
git commit -m "Add: Short description of the change"
```

4. Push the branch.

```bash
git push origin feature/your-feature-name
```

5. Open a Pull Request.

---

## Contribution Guidelines

Please ensure that:

- Code follows Python best practices.
- New functionality includes appropriate documentation.
- Existing functionality is not broken.
- Notebook outputs are cleared before committing (unless required).
- Documentation is updated when necessary.

---

## Reporting Issues

If you discover a bug or have a feature request, please open a GitHub Issue describing:

- The problem
- Steps to reproduce
- Expected behavior
- Actual behavior
- Environment details (Python version, TensorFlow version, etc.)

---

## Questions

If you have questions about the project, please create a GitHub Issue.

Thank you for helping improve this project!
