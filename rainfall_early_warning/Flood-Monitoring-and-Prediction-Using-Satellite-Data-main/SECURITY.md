# Security Policy

## Supported Versions

This repository is provided for educational and research purposes.

The latest version of the project receives documentation updates and improvements.

## Reporting a Vulnerability

If you discover a security issue or vulnerability related to this repository, please open a GitHub Issue or contact the repository owner.

Please include:

- Description of the issue
- Steps to reproduce
- Expected behavior
- Actual behavior
- Environment information

Thank you for helping improve this project.
